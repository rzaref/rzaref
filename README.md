### 🛡️ SetaGuard at a glance

**Discover services. Inspect configuration. Keep the evidence.**

A Python / Qt desktop workspace with English and Persian interfaces, bounded network checks, local scan history, and clear HTML / JSON reports.

- **Visibility:** TCP discovery, DNS, TLS, HTTP, and optional service/version evidence.
- **Clarity:** Findings show their evidence and limitations.
- **Control:** Local data, optional public-IP lookup, and deliberate release verification.

*Development preview. AI inference and traffic analysis are not current SetaGuard features.*
